# React Blog Site

A simple personal blog built with React components and props.

## Features

- Reusable React components
- Props-based data flow
- Dynamic article rendering
- Component organization
- Basic testing with Jest

## Components

- Header
- About
- ArticleList
- Article

## Installation

```bash
npm install
```

## Run Project

```bash
npm run dev
```

## Run Tests

```bash
npm test
```

## Technologies Used

- React
- Vite
- JSX
- CSS
- Jest
